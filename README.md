# cardini.dev

Felipe Cardini's portfolio. One static page, no client framework, about **18 KB** on first load.

Built with Astro + TypeScript (strict). All copy lives in [`src/content/site.ts`](src/content/site.ts). To change it, edit that file and push; the site redeploys automatically.

## Run it

```sh
npm install
npm run dev        # http://localhost:4321
npm run build      # outputs to dist/
npm run weight     # first-load size against the 100 KB budget
```

Needs Node 22.12 or later.

## Decisions

| Decision                                        | Why                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Astro**, not Next.js                          | The page is static content. Astro ships zero JavaScript by default; Next.js would ship a React runtime this page doesn't use.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **Typed data file**, not a CMS                  | One person edits the content, rarely. Interfaces for case studies and projects catch mistakes at build time.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| **System font stack**                           | Zero font bytes. That keeps the weight and carbon targets easy to hit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| **Plain CSS with tokens**                       | One accent, one spacing scale (4/8/16/24/40/64), one type scale, all in [`global.css`](src/styles/global.css). Dark mode just redefines the tokens.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **CSS inlined into the HTML**                   | The stylesheet is tiny, so the page renders from a single request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| **Web3Forms** for the contact form              | The old EmailJS + Gmail setup broke silently (`412 Invalid grant`) and lost enquiries. Web3Forms has no OAuth token to expire.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Inline scripts minified at build**            | Astro ships `is:inline` scripts as written; the build step runs them through esbuild so comments and whitespace never ship.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **Progressive-enhancement form script** (~1 KB) | Without JS the form posts normally and lands on `/thanks/`. With JS it sends in place and, if sending fails, shows an error with the email address. A failure can't be silent.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| **Nullable links** (`linkedin`, `cv`, form key) | Anything not ready yet is `null` and disappears from the page, so a placeholder can never ship as a broken link.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **Neon name** (Monoton, OFL)                    | The one bit of personality, and a nod to the neon titles of the first cardini.dev. Subset to the letters of the name and role (2.5 KB), served as "Cardini Neon" because Monoton is a Reserved Font Name. Glows in dark mode with an irregular short-circuit flicker (two faults on unrelated cycles, max 3 flashes per second), with a CSS-only "Motion" switch to pause it (WCAG 2.2.2). No motion if reduced motion is set.                                                                                                                                                                                                                                                                                                                                           |
| **Carbon receipt**                              | Itemises what the page costs to load, like an order ticket: the build measures it and CO2.js turns it into CO₂. Ties together the pizzeria, TRACE and building light.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **Café scene**                                  | In the bottom-left corner, the shadows of two developers sunk into low, slouchy café sofas, laptops open on the low table, a candle in a glass jar between them, a plant behind. She has a messy bun, glasses and crossed legs; he has a hoodie and a baseball cap. They type in bursts and breathe; now and then one glances up, leans in, stretches or sips a coffee, and sometimes they look up at each other. At random a waiter brings a coffee, bends down and sets it on the table beside one of them (the bend and reach are worked out so the saucer lands on the table top). The candle (neon yellow) and the laptop screens (cool blue) are the only lights. SVG shadows; a ~2 KB script directs it. Motion switch or reduced motion: the scene stays, still. |
| **TRACE screenshots**                           | Only screens isla has published on traceyour.events (results dashboard, data entry), cropped and re-hosted as AVIF + WebP under 30 KB each by `scripts/images.mjs`, lazy-loaded, credited "Images: isla". Counted on the receipt and in the weight budget.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **GitHub Pages**                                | cardini.dev already lives there and the DNS already points there.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## Quality checks (CI, every push)

`.github/workflows/ci.yml` runs: typecheck (`astro check`), ESLint, Prettier, build, the 100 KB weight budget, a WCAG AA contrast check of the colour tokens in both themes, a broken-link check (lychee), and Lighthouse CI (Accessibility, Best Practices and SEO must be 100; Performance at least 95 to allow for CI noise).

The footer's page weight and CO₂ per visit are measured on every build by [`integrations/carbon.mjs`](integrations/carbon.mjs): gzipped first-load size, run through CO2.js (Sustainable Web Design model v4, the one Website Carbon uses), hosting counted as not green.

`scripts/og.mjs` regenerates the Open Graph image (`public/og.png`, ~9 KB).

## Going live

1. Push this repo to GitHub (e.g. `felcard/cardini.dev`).
2. Settings → Pages → Source: **GitHub Actions**. The deploy workflow publishes on every push to `main`.
3. Settings → Pages on the **old** repo (`felcard.github.io`): remove the `cardini.dev` custom domain.
4. Settings → Pages on **this** repo: set the custom domain to `cardini.dev` and tick "Enforce HTTPS". No DNS changes are needed.
5. Send a test enquiry through the form and check it arrives. Repeat every month or two.
6. Take the old site down (see the brief, section 8).
